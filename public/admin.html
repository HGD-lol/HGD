⚠ 계정(닉네임)이 저장되지 않는 상태입니다

Supabase members 테이블에 nicks 컬럼이 없어, 계정 추가·삭제·대표 변경이 화면에만 반영되고 DB 에는 남지 않습니다. SQL Editor 에서 아래를 실행하세요.

alter table public.members add column if not exists nicks jsonb not null default '[]'::jsonb; update public.members set nicks = to_jsonb(array[nick]) where coalesce(nicks, '[]'::jsonb) = '[]'::jsonb and coalesce(nick, '') <> '';
새 단원을 명단에 올립니다

주라인 1개, 부라인 최대 2개를 선택하세요. 부계정은 추가한 뒤 아래 목록의 [관리] 버튼에서 등록합니다.
